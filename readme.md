# ПЛАТФОРМА ДЛЯ ОНЛАЙН-БРОНИРОВАНИЯ ТУРОВ И ЭКСКУРСИЙ
## Цель проекта
Целью проекта является закрепление командой разработчиков навыков, полученных при прохождении курса 
дополнительной профессиональной подготовки по WEB-разработке.
## Задача проекта
Задачей, стоявшей перед командой разработчиков, была разработка платформы, помогающей в планировании 
активного досуга: нахождении и бронировании туров и экскурсий.
## Что содержит репозиторий
Репозиторий содержит клиентскую часть, реализованную на React.js, и серверную часть, реализованную
на Django. Клиентская часть находится в папке "canada_tours_front", а серверная - в "canada_tours_back"
## Как запустить
Для того, чтобы запустить проект, необходимо произвести начальную настройку
### Настройка клиентской части
Для того, чтобы поднять сервер с React, необходимо перейти в папку "canada_tours_front", открыть консоль
и выполнить команды:
* Для установки пакета Node.js:
```bash
npm install
```
* Для установки пакета, позволяющего взаимодействовать DRF и React
```bash
npm install axios
```
### Настройка серверной части
1. В папке "canada_tours_back" открыть терминал и выполнить команду
   ```bash
   python -m venv venv
   ```
2. После создания виртуального окружения, необходимо активировать его 
и загрузить необходимые зависимости с помощью следующих команд
   * активация окружения
    ```bash
    .\venv\Scripts\activate
    ```
   * установка зависимостей
    ```bash
    pip install -r requirements
    ```
3. Далее необходимо в папке "canada_tours_back/canada_tour" создать два файла
   * SECRET_KEY.py<br>
   Данный файл содержит секретный ключ, использующийся Django для защищенной
   передачи данных с форм. В репозитории он уже дан, но для безопасности его лучше заменить.
   * db_setting.py<br>
   Данный файл содержит настройку подключения к базе данных. В качестве базы данных можно выбрать 
   любой движок: sqlite3, PostgreSQL, MySQL и другие. В нашем проекте использовался PostgreSQl.
   Ниже показан шаблон настройки подключения к PostgreSQL.<br>
   ```
   DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': '<название_таблицы>',
        'USER': '<имя_пользователя>',
        'PASSWORD': '<пароль>',
        'HOST': 'localhost',
        'PORT': <порт>,
    }
   ```
   
## Запуск проекта
Для запуска проекта необходимо выполнить две команды:
* В папке "canada_tours_front" для запуска сервера клиентской части
  ```bash
  npm start
  ```
* В папке "canada_tours_back/canada_tour" для запуска серверной части
  ```bash
  python manage.py runserver
  ```
  
После запуска серверов откроется главная страница проекта. Она будет пуста, т.к. в базе данных
не хранится никаких данных. При желании можно создать собственные данные через админ-панель Django, 
либо загрузить подготовленные нами фикстуры.
### Добавление данных через admin-панель
Для начала в папке "canada_tours_back/canada_tour" необходимо выполнить команды
```bash
python manage.py makemigrations
```
```bash
python manage.py migrate
```
Данные команды сформируют таблицы в базе данных.

После этого необходимо создать супер-пользователя командой
```bash
python manage.py createsuperuser
```
Заполнив данные, появится пользователь-админ, с помощью которого можно добавлять данные.
Для этого необходимо зайти на URL:

```URL
localhost:8000/admin
```
Откроется окно входа в админ-панель. Вводите логин-пароль и у вас открывает панель 
редактирования данных.

Если у вас не получается войти в админ-панель под созданным пользователем, то выполните
```bash
python manage.py makemigrations
```
```bash
python manage.py migrate
```
### Добавление данных через фикстуру
Для того, чтобы ввести в базу подготовленную нами фикстуру необходимо в папке 
"canada_tours_back/canada_tour" выполнить команду
```bash
python manage.py loaddata db.json
```

После выполнения данной команды, в базе данных появятся созданные нами туры и экскурсии.

### Сохранение фикстур
В процессе разработки наша команда столкнулась с проблемой синхронизации данных, находящихся в базе данных.
Чтобы устранить данную проблему мы нашли вот такую команду для сохранения фикстур БД:
```bash
python -Xutf8 manage.py dumpdata --exclude auth --exclude admin --exclude sessions --exclude contenttypes --indent 4 -o db.json
```
Данная команда сохраняет ТОЛЬКО данные туров, исключая административные данные Django.
